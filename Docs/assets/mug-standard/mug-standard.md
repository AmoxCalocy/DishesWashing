# 标准马克杯模型

2026-11-12 使用 Blender 5.3.0 CLI 制作，2026-11-13 完成交付检查。沿用餐盘的暖白陶瓷外观，提供真实杯内腔、圆润杯口、杯底、足圈及杯柄开口，供悬空拿取和旋转清洁使用。

## 模型规格

- 杯体最大外径 **90 mm**，高 **105 mm**；包含杯柄的总宽约 **130.75 mm**。
- 杯口内径 **83 mm**，口沿径向厚度约 **3.5 mm**；内底距足底 10 mm，中央陶瓷底厚 6 mm，内腔深约 95 mm。
- **4,178 个源顶点、8,348 个三角形**。杯体和杯柄为两个可独立编辑的封闭网格；杯柄端部嵌入外壁，两者未做布尔融合。
- 根原点位于杯体轴线的半高处；杯柄不会把旋转中心向侧面拉偏，所有物体缩放为 1。
- 两个基础 PBR 材质：暖白釉面与较粗糙的无釉足底，无外部贴图依赖。
- 杯体 `UV_Cleaning` 分为内底、内壁、外壁、外底四个不重叠区域；杯柄使用独立 `UV_Handle`。杯体与杯柄拥有各自的 UV 空间，后续做连续污渍遮罩时应分别分配遮罩。
- Blender 顶点组 `Clean_Interior`、`Clean_Exterior`、`Clean_Underside` 方便编辑选区，不作为 Godot 清洁分区数据。

## 节点和方向

```text
Mug_Standard
├── Mug_Body
├── Mug_Handle
├── Placement_Base
├── Mouth_Center
├── Dirt_Inner_Bottom
├── Dirt_Inner_Wall
├── Dirt_Outer_Wall
├── Dirt_Underside
└── Dirt_Handle
```

默认杯口朝 Blender `+Z` / Godot `+Y`，杯柄朝 `+X`。导入 Godot 后，杯体尺寸为 `(0.09, 0.105, 0.09)` 米，足底与杯口分别位于局部 `y=-0.0525`、`y=0.0525`。

`Placement_Base` 用于平放时对齐支撑面；`Mouth_Center` 用于杯口定位。灰盒托盘表面为 Blender `z=0.9295`，杯体原点应放在 `z=0.982`；右侧杯垫顶面为 `z=0.913`，对应杯体原点 `z=0.9655`。正式放置仍需检查杯柄方向和周围资产的间距。

五个 `Dirt_*` 节点分别位于内底、内壁、外壁、外底和杯柄表面。节点局部 Blender `+Z` / Godot `+Y` 表示朝外方向；内壁的朝外方向指向杯内空气。`test_radius_m` 仅提供污渍测试范围，实际工具贴合需要使用网格命中法线。

拿取时移动和旋转同一个 `Mug_Standard` 实例。Godot 中从单位姿态绕 X 轴旋转 90°，可使杯口朝向相机局部 `+Z`；再根据需要倾斜以观察内壁或翻转检查外底。五张预览展示了不同观察姿态，不限制游戏内旋转。

## 海绵进入杯口的验证范围

现有海绵尺寸为 110 × 70 × 32 mm。测试让 **110 mm 长轴沿杯轴进入**，将 70 × 32 mm 截面的中心放在杯轴上。该截面包围矩形的对角线约 76.97 mm，小于 83 mm 的杯口内径；海绵原点在绿色擦洗面，因此定位时额外补偿了 16 mm 厚度中心偏移。

预览中的海绵伸入杯口约 **40 mm**，其余部分留在杯外。脚本对位于杯口以下的网格顶点与内壁截面进行了抽样比较，最小径向余量约 **1.9 mm**，并查看了实际渲染中的入口位置。

这项检查证明该姿态具有进入杯口的空间，不代表已经验证深入杯底或完整贴合内壁。杯底较窄且带圆角，海绵现有压缩形态也不会弯曲包住圆柱内壁；杯内擦洗仍需实现局部接触、朝向调整和有效清洁范围限制。

## 已完成的检查

- Blender 检查杯体和杯柄的闭合性、非退化面、朝外法线及 UV 范围。
- 从杯口向下的射线命中内底；从下方向上的射线命中外底；从杯内向侧面命中朝内的内壁法线。
- 从杯柄开口中央穿过的射线不命中杯体或杯柄，确认开口未被封住。
- 普通拿起、近距清洁和翻底时，杯体与杯柄均在画面范围内，并避开近裁剪面。
- Godot 4.7.2 通过 `GLTFDocument` 成功读取并实例化最终 GLB，确认杯体尺寸、8,348 个三角形、UV、法线、10 个节点与定位方向；预览地面和灯光未进入导出。

本次完成独立模型和清洁定位准备。杯内碰撞查询、污渍可见层、工具跟随及放置逻辑仍需在 Godot 游戏场景接入。清洁查询应保留实际内腔和杯柄开口，单个凸包不能准确代表这些表面。预览临时加载已有灰盒及海绵，未覆盖它们的源文件，也未把正式杯子写回灰盒。

## 重建

在项目根目录执行以下命令，会覆盖本马克杯的 `.blend`、`.glb` 和五张预览。手动修改模型后，应先保存编辑版本再重建。

```powershell
& 'D:\Blender\blender.exe' --background --factory-startup --python-exit-code 1 --python 'Tools/build_standard_mug.py'
```
