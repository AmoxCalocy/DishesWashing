## 尺寸与结构

| 部位 | 尺寸或做法 |
| --- | --- |
| 台面 | 2600 × 800 mm，厚 40 mm，边缘带 2 mm 倒角 |
| 开孔 | 孔壁截面 920 × 540 mm，圆角半径 65 mm；表面倒角处约 924 × 544 mm |
| 水槽外沿 | 960 × 580 mm；与开孔四周搭接约 18～20 mm |
| 水槽内口 | 盆口处约 860 × 500 mm，向下略收窄，底角圆滑 |
| 盆深 | 约 250 mm；盆沿最高点至排水孔处约 257 mm |
| 盆壳 | 有实际内外壁和底部厚度；盆沿下搭接面位于台面顶面，不悬空 |
| 盆底排水孔 | 直径 90 mm，贯穿盆壳 |
| 排水法兰 | 外径 116 mm，包含滤片承托圈、收口和中空短尾管 |
| 滤水片 | 直径 80 mm，厚 2 mm，十二条圆角径向槽孔 |
| 短尾管 | 内径 60 mm、外径 66 mm；末端位于台面以下 325 mm |

模型共 **10,578 个源顶点、21,200 个三角形**，四个网格、三个基础 PBR 材质。水槽为缎面不锈钢，排水组件较亮，台面使用暖木色基础材质；当前不含木纹贴图或额外拉丝纹理。所有网格已展开 UV，无外部贴图依赖。

`Sink_Basin` 的材料边界闭合，但盆口和排水孔保持畅通；台面和滤片也各自保留真实孔洞。排水法兰、滤片与盆壳为独立部件，不依赖贴图模拟孔洞。滤片底面落在法兰承托圈上。

## 节点与放置

```text
Sink_Countertop
├── Countertop_Cutout
├── Sink_Basin
├── Drain_Assembly
│   ├── Drain_Flange_And_Outlet
│   └── Drain_Strainer
├── Countertop_Surface
├── Cutout_Center
├── Drain_Center
├── Drain_Outlet
├── Faucet_Mount
├── Faucet_Switch_Mount
├── Sponge_Rest_Surface
├── Plate_Return_Surface
└── Mug_Return_Surface
```

根原点是台面顶面的平面中心。安装到现有操作区时，根节点放在 Blender `(0, 0, 0.90)` / Godot `(0, 0.90, 0)`，保持单位缩放。开孔和排水中心在 Blender 局部 `y=-0.02`，对应 Godot 局部 `z=+0.02`。

下表使用 **Blender 世界坐标**，已包含台面 0.90 m 的安装高度。Godot 对应映射为 `(x, z, -y)`。

| 定位点 | 位置/用途 |
| --- | --- |
| `Faucet_Mount` | `(0.16, 0.320, 0.900)`，龙头底座安装面 |
| `Faucet_Switch_Mount` | `(0.305, 0.320, 0.900)`，独立开关底座安装面 |
| `Sponge_Rest_Surface` | `(-0.30, 0.17, 0.9285)`，现有海绵托板上表面 |
| `Plate_Return_Surface` | `x=-0.23, y=0.045`，高度由盆底射线取得 |
| `Mug_Return_Surface` | `x=0.23, y=0.10`，高度由盆底射线取得 |
| `Drain_Outlet` | `(0, -0.02, 0.575)`，短尾管下端中心 |

餐具返回点是表面点，不是餐具中心。盆底略向排水口倾斜，正式放置需结合餐具足底、轮廓和局部坡度计算姿态。预览使用正式餐盘和马克杯，逐顶点比较餐具与下方盆底的高度，调整到最小竖向余量 0.5 mm，用于检查静态摆放空间；这不等于已经实现物理吸附或放置规则。

原灰盒龙头底座和开关底座的高度、前后位置与正式盆沿存在偏差。本轮只在集成预览中将它们对齐新安装点。海绵支架底面为 `z=0.907`，与新盆沿最高面一致，托板及支架无需整体抬升。未来制作正式龙头与托架时，以本模型定位点复核。

## 验证与接入范围

- 检查四个网格的闭合性、非退化面和朝外法线。
- 分别用射线确认台面开孔、盆底排水孔、短尾管中央及滤片槽孔未封闭，并确认滤片中心仍有实体。
- 从盆沿下方命中局部 `z=0` 的搭接面，确认其落在台面上。
- 从盆口命中两侧盆底，检查正式餐盘、马克杯的静态支撑及摆放余量。
- 查看独立全貌、开孔、排水细节、玩家视角和操作区预览。
- Godot 4.7.2 通过 `GLTFDocument` 成功读取并实例化 GLB，验证尺寸、UV、法线、金属材质、21,200 个三角形与 15 个节点；预览相机和灯光未进入导出。

`01_Sink_Countertop_Asset` 是正式模型集合；`90_Preview_Studio` 仅用于预览。操作区预览中的龙头、开关、海绵托架和其他背景仍是已有灰盒占位，未包含在本次 GLB 中。原灰盒文件保持原样，正式操作区的整体组装仍待进行。

游戏中还需配置静态碰撞、水流、积水、音效和餐具放置逻辑。碰撞应保留盆内腔与台面开孔，不能给整个组合套一个封闭凸包。排水口当前提供几何和定位，无排水模拟或滤片交互。

## 玩法接入补充（2026-11-26）

第 12 步已验收真实水槽表面的自由落点预览，第 13 步及追加需求已验收实际放置、再次拿取与盘杯交叠堆放，玩家不受固定盘位／杯位限制。GLB 中 Plate_Return_Surface、Mug_Return_Surface 保留为历史几何参考，不是玩法落位目标；正式配置中的两个水槽固定槽位及可见标记已移除。当前玩法使用真实盆体与排水口三角面、底圈支撑和最终空间判定，排除台面与边沿；只有沥水架提供固定位置。餐具按实际槽底及陶瓷支撑自动抬高，保留厚度并记录支撑身份；先移走上层才能拿取下层，不模拟自由滚落或刚体平衡。自由位置由原节点完整姿态记录，不产生水槽槽位。Q 安全返回在第 14 步，水流与清洗仍待后续。本次未修改模型和生成器。现行画面和规则见[可玩入口说明](../../scenes/kitchen-game/kitchen-game.md)，上文资产交付与静态预览记录保留当时范围。

## 重建

在项目根目录运行，会覆盖本组合的源模型、GLB 和五张预览。手动编辑源模型后，应先保存编辑版本再重建。

```powershell
& 'D:\Blender\blender.exe' --background --factory-startup --python-exit-code 1 --python 'Tools/build_sink_countertop.py'
```
